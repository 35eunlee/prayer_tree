# 기도나무 (Prayer Tree)

기도제목을 기록하고, 그룹·친구와 함께 기도하며, 응답과 말씀 편지를 모아보는 웹 앱입니다.

## 주요 기능

- 개인 기도제목, 카테고리, 응답 기록과 기도 달력
- 그룹·친구 초대, 그룹 중보기도와 기도 인증
- 말씀과 묵상을 기록하는 기록 탭
- 말씀 편지 작성, 편지함, 익명 답장
- 나무 꾸미기와 기도 중 비 효과

## 실행 환경

이 프로젝트는 Next/Vinext 앱과 Sites 플랫폼의 서버 기능을 사용합니다. GitHub Pages 같은 정적 호스팅만으로는 그룹, 친구, 로그인, 공유 기능이 작동하지 않습니다.

필요 항목:

- Node.js 22.13 이상
- Git
- Sites 호스팅과 D1 데이터베이스 바인딩 `DB`

로컬 실행:

```bash
npm install
npm run dev
```

## 새 Sites 프로젝트로 복제하기

1. 이 저장소를 GitHub에서 Fork하거나 Clone합니다.
2. Sites에서 새 프로젝트를 만들고 이 저장소를 연결합니다.
3. 새 프로젝트가 발급한 프로젝트 ID와 데이터베이스 바인딩을 설정합니다. 원본 사이트의 ID나 데이터는 복사하지 마세요.
4. `drizzle/0000_mean_invaders.sql`부터 `drizzle/0009_record_kinds.sql`까지 마이그레이션을 순서대로 새 D1 데이터베이스에 적용합니다.
5. 새 Sites 프로젝트에서 빌드·배포하고 로그인 및 그룹 기능을 확인합니다.

> 저장소에는 원본 Sites 프로젝트 ID와 기존 배포 파일을 포함하지 않습니다. 각 복제본은 자체 사이트 설정과 D1 데이터베이스를 사용해야 합니다. 기존 사이트 사용자 데이터는 복제되지 않습니다.
