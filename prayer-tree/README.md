# 기도나무

함께 기도하고, 기도제목과 말씀을 기록하며, 말씀 편지를 주고받는 웹앱입니다.

## 로컬 실행

- Node.js 22.13 이상과 npm이 필요합니다.
- `npm ci`
- `npm run dev`

프로덕션은 Cloudflare Workers 기반 Sites 런타임과 D1 데이터베이스를 사용합니다. 따라서 GitHub Pages에 파일만 올리는 방식으로는 로그인, 그룹, 친구, 편지 등의 서버 기능이 동작하지 않습니다. 별도 배포를 하려면 D1 `DB` 바인딩과 `db/`의 마이그레이션을 설정해야 합니다.

이 저장소는 애플리케이션 소스 코드이며, 기존 운영 사이트의 사용자 데이터는 포함하지 않습니다.
